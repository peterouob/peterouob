## Selected Work

| Project | What it is |
|---|---|
| [**lock-free-priority-queue**](https://github.com/peterouob/lock-free-priority-queue) | Concurrent PQ from the Mounds paper, with a self-built DCSS primitive. 2x throughput over a mutex heap at 8 workers. |
| [**gocloud**](https://github.com/peterouob/gocloud) | LSM-tree storage engine (MemTable / SSTable / WAL / compaction), deployed to AWS EKS via Argo CD. |
| [**Raft**](https://github.com/peterouob/Raft) | Raft consensus from scratch — leader election and log replication over gRPC. |
| [**HTTP**](https://github.com/peterouob/HTTP) | HTTP/1.1 server built up from raw TCP on Tokio. |
| [**seckill_service**](https://github.com/peterouob/seckill_service) | Flash-sale microservices. Zero overselling under 10k-thread load. |
